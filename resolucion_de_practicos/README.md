# Resolucion de practicos

Soluciones desarrolladas desde cero para los tres practicos de Fundamentos de la Ciencia de Datos.

## Orden recomendado

1. Abrir los notebooks con el kernel `Python (.prac)`.
2. Ejecutar `Practico_1_resuelto.ipynb`.
3. Ejecutar `Practico_2_resuelto.ipynb`; los datos se descargan en `datos/` si no existen.
4. Ejecutar `Practico_3_resuelto.ipynb`; los reportes se guardan en `reportes/`.

Los notebooks usan los conceptos de las guias de Obsidian: funciones, estructuras de datos,
Pandas, inspeccion de DataFrames, filtros, agrupamientos, correlacion y visualizacion.

Las dependencias estan listadas en `requirements.txt`. El entorno recomendado es `Python (.prac)`.

La clase 4 no forma parte de estas resoluciones.
